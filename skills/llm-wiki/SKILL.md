# /llm-wiki — LLM 지식 참조

LLM 관련 개념, 기법, 모델 특성을 즉시 참조합니다.
구현 중 LLM API 선택, 프롬프팅 전략, 아키텍처 결정이 필요할 때 사용합니다.

## 커버 범위

### 모델 선택

- 작업 복잡도에 따른 모델 티어 (fast / standard / heavy)
- Claude: haiku → sonnet → opus
- OpenAI: gpt-5.4-mini → gpt-5.5 → gpt-5.5
- 비용 vs 품질 트레이드오프

### 프롬프팅 기법

- **시스템 프롬프트**: 역할 정의, 출력 형식 강제
- **Few-shot**: 예시로 패턴 학습
- **Chain-of-Thought**: 단계적 추론 유도
- **XML 태그**: Claude에서 구조화된 입출력
- **프롬프트 캐싱**: 반복 컨텍스트 비용 절감

### RAG / 컨텍스트 관리

- 컨텍스트 윈도우 한계 인식
- 관련 청크만 포함, 불필요한 컨텍스트 제거
- 임베딩 기반 검색 vs 키워드 검색 선택 기준

### 일반 실수

- 할루시네이션: 사실 확인 없이 출력 신뢰 금지
- 컨텍스트 오염: 불필요한 이전 대화 누적
- 과도한 지시: 프롬프트가 길수록 지시 희석
