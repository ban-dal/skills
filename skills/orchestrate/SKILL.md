# /orchestrate — 서브 에이전트 위임

메인 모델이 자체 판단으로 서브 에이전트를 소환해 작업을 수행합니다.
plan, brainstorm, code-review 등 독립적으로 처리 가능한 작업을 위임합니다.

## 소환 기준

요청 의도와 파일 영향 범위로 판단합니다:

| 의도      | 파일 ≤ 2    | 파일 3–5            | 파일 6+             |
| --------- | ----------- | ------------------- | ------------------- |
| 버그 수정 | 바로 수정   | 바로 수정           | 플래너 소환         |
| 기능 추가 | 간단한 계획 | 플래너 소환         | 플래너 소환 (heavy) |
| 리팩토링  | 간단한 계획 | 플래너 소환         | 플래너 소환 (heavy) |
| 아키텍처  | 플래너 소환 | 플래너 소환 (heavy) | 플래너 소환 (heavy) |

## 서브 에이전트 유형

**플래너**: 구현 전 단계별 계획 수립

- 관련 코드베이스 분석
- 구체적인 구현 계획 + 위험 요소 파악
- 계획 반환 → 메인 모델이 검토 후 실행

**브레인스토머**: 가능한 접근법 탐색

- 여러 구현 방향 나열 및 트레이드오프 비교
- 확정하지 않고 선택지만 제시

**리뷰어**: 구현 완료 후 검증

- 정확성, 누락된 엣지 케이스, 범위 초과 확인
- 변경 파일 5개 이상이거나 사용자가 리뷰를 요청할 때 소환

## 모델 티어

| 티어     | Claude | OpenAI       | 사용 목적                              |
| -------- | ------ | ------------ | -------------------------------------- |
| fast     | haiku  | gpt-5.4-mini | 조회, grep, 단순 포맷 확인             |
| standard | sonnet | gpt-5.5      | 계획 수립, 코드 리뷰, 중간 복잡도 분석 |
| heavy    | opus   | gpt-5.5      | 복잡한 아키텍처, 모호한 요구사항       |

## 규칙

- 명시적 요청 없이 테스트 작성, 범위 밖 리팩토링, 불필요한 추상화 추가 금지
- 서브 에이전트 결과를 검토하지 않고 바로 실행하지 않습니다
