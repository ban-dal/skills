# Workflow 출력 형식

`workflow-architect`와 모든 하위 실행 Skill은 작업의 Workflow(실행 계획)를 아래 형식으로 출력한다.
새 Skill 파일을 만들지 않는다. 작업 성격에 맞지 않는 항목은 비우지 말고 "해당 없음"으로 표시한다.

```
1. 문제·목표        — 무엇을, 끝났다고 말할 체크 가능한 조건
2. Task 목록        — 각 Task에 [목표 · 완료 기준 · 예상 변경 파일 범위]
3. 의존성 그래프    — Task 선행관계 (없으면 "없음")
4. 병렬 계획        — 병렬 / 순차 / 머지-후 분류
5. Agent Task Card  — 병렬 작업마다 7필드 (agent-strategy.md)
6. 리뷰 단위        — PR/커밋 단위 + 분할 근거
7. 검증 전략        — 선택한 검증 + "검증 완료" 기준
8. 실행 순서표      — 실행자가 그대로 따라갈 순서
```

## 규칙

- **추상 금지** — "잘 분해한다"가 아니라 이 작업에서 실제로 나오는 Task를 적는다.
- **완료 기준은 체크 가능하게** — "개선됨"이 아니라 "X 입력 시 Y 반환 / 테스트 N개 통과".
- **모델 비종속** — sub-agent 같은 기능은 항상 대안(순차·수동)과 함께 적는다.
- 단일 파일·소규모 작업이면 4·5(병렬·Agent)를 "해당 없음"으로 두고 단일 순차로 출력한다.
