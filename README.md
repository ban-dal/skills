# ban-dal/skills

Claude Code, Codex 등 AI 코딩 에이전트용 스킬 컬렉션입니다.

## 설치

```bash
npx skills@latest add ban-dal/skills
```

## 스킬 목록

| 스킬            | 설명                                                                          |
| --------------- | ----------------------------------------------------------------------------- |
| `/agentic-work-log` | AI 코딩 작업 수행 기록 — 한국어 Markdown 작업 로그 작성 및 갱신          |
| `/llm-wiki` | LLM Wiki 지식 조회, 프로젝트 메모리 기록, 재사용 지식 정리          |
| `/workflow-architect` | 개발 작업 분류 후 Workflow(실행 계획) 설계 — 메타 라우터, 공통 원칙 소유 |
| `/implement-feature` | 기능 구현 Workflow 설계 — 요구 분석·계층 분리·계약 우선 병렬화·검증 |
| `/bugfix` | 버그 수정 Workflow 설계 — 재현·원인 격리·최소 수정·재발 방지 검증 |
| `/refactor` | 리팩터링 Workflow 설계 — 동작 보존·안전망·작은 가역 단계·회귀 검증 |
| `/review` | 코드 리뷰 Workflow 설계 — 의도 파악·위험 정렬·관점별 리뷰·Blocker/Suggestion 분리 |
| `/test-generator` | 테스트 작성 Workflow 설계 — 명세 식별·핵심/엣지 분리·검증 수준 판단·기존 스타일 준수 |
| `/performance` | 성능 개선 Workflow 설계 — 측정 기준·병목 식별·가설 기반 개선·Before/After 검증 |
| `/migration` | 마이그레이션 Workflow 설계 — 불변식 정의·호환성 위험·단계적 전환·롤백 전략 |
